# Issues Identified - Task Management Application

## 1. Variables and Operators

### app.js - Global Variables (top of file)

**Issue:** Variables were missing proper declarations.

* `taskList` was created without `const`, `let`, or `var`.
* This could create unwanted global variables and cause scope problems.

**Required fix:** Declare variables using `const` or `let`.

---

### app.js - updateTaskPriority() function

**Issue:** Incorrect comparison and validation logic.

Problems found:

* Missing validation for `null` and `undefined` parameters.
* Missing data type checks.
* Incorrect operator usage could cause incorrect comparisons.

**Required fix:** Add validation and use strict comparison operators (`===`).

---

## 2. Control Flow and Loops

### app.js - displayAllTasks() function

**Issue:** Loop implementation needed improvement.

Problem found:

* Loop structure contained unnecessary indexing and risked off-by-one errors.

**Required fix:** Use a `for...of` loop to directly iterate through tasks.

---

### app.js - findTaskByTitle() function

**Issue:** Function was incomplete.

Problem found:

* Missing function parameter.
* Loop and comparison logic needed correction.

**Required fix:** Add the `title` parameter and use correct comparison operators.

---

## 3. Functions and Functional Programming

### app.js - addTask() function

**Issue:** No error handling was implemented.

Problems found:

* Empty task titles were accepted.
* No validation was performed before adding tasks.

**Required fix:** Add validation and use try/catch error handling.

---

### app.js - countCompletedTasks() function

**Issue:** Recursive function was incomplete.

Problems found:

* Missing validation for invalid input.
* Recursive logic required a proper base case.

**Required fix:** Add null/undefined checks and ensure recursion stops correctly.

---

### app.js - calculateAveragePriority()

**Issue:** Missing handling for empty task lists.

Problem found:

* Function could fail or return incorrect values when no tasks existed.

**Required fix:** Add empty array validation.

---

## 4. Object-Oriented Programming

### app.js - Task class constructor

**Issue:** Task class was incomplete.

Problems found:

* Required properties were not fully implemented.
* Missing task ID assignment.

**Required fix:** Add all required properties including `id`.

---

### app.js - Task class methods

**Issue:** Missing completion functionality.

Problem found:

### app.js - SubTask class

## Summary of Major Issues Found

The starter application contained issues involving:

* Variable scope and declarations
* Incorrect operators
* Loop errors
* Missing function parameters
* Missing error handling
* Incomplete classes and inheritance
* Missing ES6 features
* Incorrect DOM handling
* Missing localStorage functionality
* Incomplete Jest tests

These issues were corrected to create a functional task management application using modern JavaScript practices.
